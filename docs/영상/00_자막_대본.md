## 편집 메모
- 음성 장면(0:27)은 에뮬레이터에 Gleo 음성 앱이 없어 Gleo와 같은 신호로 재현했다. 자막으로 말풍선을 띄우고, 실제 음성은 따로 녹음해 입힌다.
- 숏폼 구성: 첫 화면 3초 → 주행 2배속 3.5초 → 주차·카드 4초 → 음성 4초 → 결산 6초 → QR 7초. 자막 파일·필터는 Claude 작업 폴더에 있으며 다시 만들 때 요청하면 된다.
- 숏폼 게시(유튜브·인스타 등)는 외부 공개라 사장님이 직접 올리고, 접수양식 8번에 링크를 적는다.
