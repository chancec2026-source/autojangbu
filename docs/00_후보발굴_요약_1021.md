## 2. 플랫폼에서 확인한 것
- Pleos Connect = 안드로이드 오토모티브. 공식 개발은 Kotlin/Java. Flutter는 문서에 없음(설명회에서 확인)
- 에뮬레이터: Android Studio용 Pleos Connect v2.1.0(API 34), 로그인 없이 받음. 샘플: GitHub Pleos-Playground/pleos-sample-vehicle-app
- 읽을 수 있는 차량 데이터(문서에 기능 이름 확인):
  - Odometer: 계기판 누적거리(getCurrentDistanceDriven), 트립 거리·시간, 주유 후 거리·시간
  - Fuel: 연료 %(getFuelPercent), 연비(누적·순간 등)
  - Seat: 착석(getCurrentSeatOccupancy), 안전띠(getCurrentSeatBeltBuckledState), 시트 위치
  - Safety: 경고등(telltales), 오일·브레이크액, 안전띠 경고, 에어백
  - Brake: 브레이크 페달 상태. 그 밖에 TurnSignal, Light, Wiper, Door, HVAC, EvBattery
  - 속도: 안드로이드 기본 PERF_VEHICLE_SPEED
  - NaviHelper: 목적지·경로·충전 정보
- **Toll = 하이패스 안내 음량만**(통행료 금액 없음). 핸들 각도·기어는 미확인
- 호환 표(api-compatibility-availability): **TTS·STT SDK '완전 호환'**, 위치(FusedLocation)는 차종별(isSupported로 확인), NaviHelper는 내비 장착 차만. 다른 문서엔 '준비 중' 표기도 있어 설명회에서 확인. 차량 제어(set)는 CONTROL 권한 필요, 공개 범위 미확인
- 상상팀 보고(직접 확인 못 함): Light로 상향·하향·안개등 상태 읽기, 깜빡이 값은 좌·우·꺼짐뿐(비상등 값 없음), 경고등 종류에 ESC·ABS·노면 결빙
- 음성 비서 Gleo: App Schema로 함수 등록, 음성 호출 함수 최대 3개
- 주행 중 사용 가능 분류: 음악/오디오 · 내비 · 모빌리티(제한적). 주행 중 영상·게임·웹 금지
- 탑재 차종(국내): 더 뉴 그랜저(2026.5), 디 올 뉴 아반떼(+투싼 보도). 앱마켓 18종(2026.9), 연말 30종+ 목표
